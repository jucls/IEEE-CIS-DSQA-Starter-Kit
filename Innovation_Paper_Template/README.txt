IEEE CIS 2026 Technical Challenge on Domain-Specific Question Answering
Methodology Paper Template
==============================================================================

This package contains the official templates for the methodology paper
that participating teams must submit to the challenge.

Both templates are based on the official IEEE Conference Template
(IEEEtran, conference mode), provided by IEEE at:
https://www.ieee.org/conferences/publishing/templates.html

CONTENTS
--------
latex/
    IEEE-conference-template-062824.tex   LaTeX source of the template
    IEEE-conference-template-062824.pdf   Compiled PDF of the template
    IEEEtran.cls                          IEEE LaTeX class file
    IEEEtran_HOWTO.pdf                    Official IEEEtran documentation
    fig1.png                              Example figure used in the template
word/
    technical_challenge_template.docx     Microsoft Word version of the template
README.txt                                This file


HOW TO USE
----------
LaTeX
    Compile IEEE-conference-template-062824.tex with pdfLaTeX. IEEEtran.cls
    is included, so no additional installation is required. The latex/
    folder can also be uploaded directly to Overleaf
    (New Project > Upload Project).

Microsoft Word
    Open technical_challenge_template.docx and type your content directly
    into the template, keeping the predefined styles.


SUBMISSION REQUIREMENTS
-----------------------
- Papers must be submitted in PDF format, regardless of the tool used.
- Maximum length: 4 pages, including references.
- Paper size: US Letter.
- All template guidance text must be removed before submission.
- Submission deadline: 10 December 2026, 23:59 UTC.
- Submissions must be sent by e-mail to gpais.taskforce@gmail.com,
  with the paper attached in PDF format.
- The e-mail must be sent from the e-mail address associated with your
  Codabench account. If this is not possible, please state your Codabench
  username and name in the body of the message so that your team can be
  identified.
- A confirmation e-mail will be sent upon receipt of your submission.
